Universal Harness is a portable, cross-platform infrastructure layer that makes DeepSeek Harness (dsh, MIT) run anywhere — a USB stick, a desktop, an Android phone — and be controlled from another machine over the local network. No account. No relay. No hosted database.

Built for machines that move

Everything is relative-path, checksum-verified and offline-first — because the point is to carry your work, not to depend on a server.

◆

Truly portable

Relative paths only. No system Node, npm, Python or Git. No symlinks (exFAT-safe). Move the folder between Windows, Linux and macOS and your projects travel with it.

⛨

LAN-first & offline

mDNS discovery, QR pairing and an encrypted, authenticated transport. Pairing binds the node's cryptographic identity into the payload, so a stolen token cannot be replayed by a different peer.

⧉

Crash-consistent

Task-state transitions and durable events commit atomically. Replay is cursor-based with snapshot fallback, so a client can never permanently infer a false task state.

⇄

Node-authoritative tasks

A task keeps running when the controller disconnects; missed events are replayed on reconnect.

⌘

Remote control

The uh connect CLI and the core/client library drive any node over the LAN — pair, inspect projects, start tasks, replay events.

⚿

Credentials never plaintext

Secrets route to device-local secure storage (Windows DPAPI) and never into the portable tree; platforms without secure storage fail explicitly instead of degrading.

Quick start

Clone, launch with the bundled runtime, and check the machine. Nothing global gets installed.

# 1 — get it
git clone https://github.com/ixboss/universal-harness.git
cd universal-harness

# 2 — launch with the BUNDLED runtime
./bin/UniversalHarness.cmd      # Windows
./bin/UniversalHarness.sh       # Linux / macOS

# 3 — verify, then run
uh setup                        # download + verify runtime + dsh
uh doctor                       # environment / runtime / workspace
uh exec "summarise this repo"
# move a workspace to another machine
uh export --out ./backup.uhbundle
uh export verify ./backup.uhbundle
uh import --bundle ./backup.uhbundle

# remote control over the LAN
uh serve                        # run a node
uh pair                         # mint a pairing payload
uh connect status               # from another machine

Portable workspace bundles

Carry a workspace between machines as a plain directory. No archive, no extractor to trust, no cloud.

  • Verify-then-commit. Every file's SHA-256 and the manifest checksum are checked before anything is written.
  • Never overwrites. A target that already differs aborts the whole import with a per-file report.
  • Nothing sensitive travels. No secrets, logs, runtime, event log or backups — enforced by an allowlist, not by convention.
  • Hostile bundles refused. Path traversal, symlinks, case/Unicode collisions and reserved names are all rejected.
# on the source machine
uh export --out /media/usb/ws.uhbundle

# on the target machine
uh export verify /media/usb/ws.uhbundle
uh import --bundle /media/usb/ws.uhbundle

# dry-run first, if you like
uh import --bundle /media/usb/ws.uhbundle --dry-run
